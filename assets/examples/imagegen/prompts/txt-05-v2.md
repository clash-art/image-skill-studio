# Text-to-image prompt

Mode: built-in `image_gen`

```text
Use case: illustration-story
Asset type: Image Skill Studio text-to-image example, portrait 3:4 raster illustration
Primary request: Create a four-panel children's picture-book comic featuring the same orange tabby cat in a clear sequential action: panel 1 the cat discovers a plain cardboard box; panel 2 the cat climbs into the box; panel 3 the box tips over with the cat inside; panel 4 the same cat sits upright beside the fallen box pretending nothing happened.
Scene/backdrop: cozy, simple indoor setting with restrained details so each action reads immediately
Subject: one consistent orange tabby cat with the same face, markings, body proportions, and expressive tail in all four panels
Style/medium: warm hand-painted watercolor children's book illustration, soft paper texture, gentle ink accents
Composition/framing: portrait 3:4 page divided into four equally clear panels in reading order; strong visual continuity; full action visible in every panel
Lighting/mood: warm, playful, tender, lightly comedic
Color palette: warm ochre, burnt orange, cream, muted wood brown
Constraints: exactly four panels; same single orange cat throughout; action sequence must be unmistakable; no speech bubbles; no captions; no letters; no logos; no watermark
Avoid: text, watermark, extra cats, redesigned cat between panels, ambiguous action, photorealism, 3D rendering
```
